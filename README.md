# RISC-V-5Stage-Pipelined-Datapath
A whole processor project of RISC_V ISA. However, the focus of project is on datapath that perform 5 stage pipelined, extended for mul/div operation and optimized to run at 125MHz

Reference: 
https://arxiv.org/pdf/2010.16171
Computer Organization and Design RISC-V edition (book)
